# 인천SW미래채움 심화과정 배포 현황판

수업에서 만든 사이트의 주제와 배포 주소를 모으는 현황판입니다. 화면 코드는 이 저장소의 `index.html`에서 관리합니다.

## 관리 원본과 접속 주소

이 저장소가 현황판 화면 코드의 관리 원본입니다. 앞으로 화면과 기능을 고칠 때는 여기서 수정합니다.

| 용도 | 주소 |
|---|---|
| 현황판 대표 주소 | https://incheonsw.vercel.app |
| 기존 자료·즐겨찾기 호환 주소 | https://swedupractice0810.vercel.app |

호환 주소는 대표 주소의 같은 경로로 자동 연결합니다. 기존 수업 자료에 어느 주소가 적혀 있어도 접속을 이어가기 위한 설정이며, 두 곳에서 화면 코드를 따로 관리하지 않습니다. 호환 연결 설정은 [swedupractice0810](https://github.com/giyoung5182/swedupractice0810)에 보관합니다.

## 기록과 외부 연결

기존 Google Apps Script 기록 연결을 그대로 사용합니다. 이번 정리는 화면 코드의 중복을 없애는 작업이며, 외부 기록 API 호출·데이터 이전·삭제·권한 변경은 하지 않았습니다.

## 통합 전 확인 기록 (2026-11-15)

두 정식 주소 모두 HTTP 200으로 응답했고, 받은 HTML이 서로 같으며 각 저장소의 파일과도 일치했습니다. 외부 연결 주소도 같았습니다. 당시 동일 화면 파일은 `9f312092e2ba3f50f42a290dd51b082582199d88`입니다.

수강생에게 실제로 공유한 주소와 방문자 통계를 확인한 결과는 아닙니다. 노션 강의자료의 주소는 노션 연결 후 별도로 확인할 수 있지만, 기존 두 주소는 호환 연결로 유지합니다.
